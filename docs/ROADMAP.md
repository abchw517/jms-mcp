# 迭代计划

## 0.1.x：完成实例兼容验收

- 在真实 JumpServer 3.10.15 社区版/企业版分别执行验收清单。
- 收集脱敏最小接口样本，补充实际 operationId、RBAC 与组织隔离回归。
- 按用户实际场景维护“资产查询”“会话审计”等精确工具配置示例。

## 后续候选

- Access Key HTTP 签名认证、自定义凭证提供器与刷新接口。
- 经实测后增加表单、文件和复杂 schema 支持。
- 提供 Prometheus 请求计数、延迟、上游错误与目录数量指标。
- 多用户身份映射、审计关联与写操作审批策略。
- 经实测后提供无状态 HTTP 多副本部署基线。

这些是规划项，当前版本未实现；不以路线图替代已交付功能。
